# Code of Conduct

## Our standards

This is an open source project focused on helping people learn about investing. Everyone who participates is expected to:

- Be respectful and constructive in all interactions
- Focus feedback on ideas and code, not on people
- Accept that maintainers make final decisions on what gets merged
- Not provide or solicit actual financial advice in issues, PRs, or discussions

## What is not acceptable

- Harassment, insults, or personal attacks of any kind
- Spam or self-promotion unrelated to the project
- Sharing other's private information without permission
- Attempting to use this project or its community to solicit financial decisions from others

## Scope

This code of conduct applies to all project spaces including GitHub issues, pull requests, discussions, and any other project-related communication.

## Enforcement

Violations can be reported by opening a private issue or contacting the maintainer directly via GitHub. The maintainer reserves the right to remove comments, close issues, and ban contributors who violate this code of conduct.

## Note on financial advice

This project provides tools and education only. No contributor, maintainer, or community member should use project spaces to give or receive financial advice. Any such content will be removed.
